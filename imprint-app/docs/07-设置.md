# 07 · 设置

路由 `#/settings`，子页 `?p=access|features|beauty|usage`。底栏「设置」、首页目录 VII、聊天页右上角「…」（直接进美化）都会进来。

预览图：`previews/07-settings.jpg`（控制台 + 入口）、`07-settings-access.jpg`（接入）、`07-settings-features.jpg`（功能管理）、`07-settings-beauty.jpg`（美化）、`07-settings-usage.jpg`（各窗口缓存命中）、`07-settings-tools.jpg`（工具调用）。

代码：`src/pages/Settings.jsx` + `src/components/settings/settings.css`；主题和气泡样式在 `src/theme/theme.js`。

## 页面上有什么

| 区块 | 说明 |
|---|---|
| 控制台 | 今日 token、本月 token、本月花费、缓存命中率，最近十来天的小折线 |
| 接入 | 每个窗口 / 群成员接的那条 Codex：名字、用在哪、在不在线；点开看调用方式、工作目录、沙箱。「新加一条接入」是预留入口（需要后端先准备好） |
| 功能管理 | **后台在跑的**：主动找你、自由活动、记忆整理、做梦、续火花结算、提醒推送，每个一个开关，写着上次跑的时间。**MCP · Codex 那边**：他能用的每个 MCP（名字、id、几个工具、连没连上），可以开关；断开的点一下重连；「加一个 MCP」填名字和地址 |
| 美化 | 主题色（蓝晒 / 雾紫 / 灰绿，马上生效、记在本地）；两人头像（点了换）；聊天背景（默认虚化蓝晒 / 相册选一张）；气泡（磨砂玻璃 / 纸片 / 蓝晒信纸）和透明度，带实时预览 |
| 用量与日志 | 三个分页：**缓存命中**（每个窗口：命中率、命中多少 / 全部输入多少 token、省了多少钱、最近 7 天的小趋势，今天和本月可切；低于 50% 标红）、**工具调用**（时间、做了什么、用的哪个工具、用时，出过问题的标红）、**后端日志**（只看警告和出错） |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

| 做什么 | 接口 | 说明 |
|---|---|---|
| 控制台 | `GET /api/settings/console` | 今日 token、本月 token、本月花费（金额 + 币种）、缓存命中率、最近每天的用量 |
| 接入 | `GET /api/connections` | 和聊天列表共用；建议再带上在线状态、调用方式、工作目录（只给末尾一段）、沙箱说明 |
| 功能管理 | `GET /api/features` | 功能（key、名字、说明、上次跑的时间、开没开）；MCP（id、名字、工具数、状态 ok / down / pending、开没开） |
| 开关功能 | `PUT /api/features/{key}` | 开 / 关 |
| 开关 MCP | `PUT /api/mcp/{id}` | 开 / 关 |
| 重连 MCP | `POST /api/mcp/{id}/reconnect` | 返回新状态 |
| 加 MCP | `POST /api/mcp` | 名字、地址 |
| 美化 | `PUT /api/settings/beauty` | 气泡样式、透明度、聊天背景地址（聊天页从 `GET /api/chats/{id}` 的聊天背景读） |
| 换头像 | 先 `POST /api/chat/upload`（kind 写 avatar），再 `PUT /api/settings/avatar` | 谁的（him / me）+ 地址 |
| 各窗口缓存命中 | `GET /api/logs/cache?range=today|month` | 每个对话：id、名字、一句说明、命中缓存的输入 token、全部输入 token、省下的钱、最近 7 天每天的命中率；币种 |
| 工具调用 | `GET /api/logs/tools` | 时间、工具名、一句标题、细节、用时、成没成功 |
| 后端日志 | `GET /api/logs/backend?level=warn` | 时间、级别、一句话 |

建议：

- **用量和缓存从哪来**：每一轮调用 Codex 后，把返回的用量（输入、缓存命中的输入、输出）按对话记一笔，再按天汇总。命中率 = 命中缓存的输入 ÷ 全部输入；「省下」按缓存价和原价的差算。
- **为什么命中率低**：人设、工作目录里的说明文件、对话开头那段如果每轮都在变，缓存就对不上。尽量把固定的放前面、变化的放后面。
- **功能开关**：关掉就是让后台那项任务停下（比如不再主动发消息、不再做梦）；开关状态存后端，所有设备一致。
- **MCP**：就是 Codex 配置里的 MCP 服务；在这里的开关、新增，由后端改 Codex 的配置，下一轮对话起生效。重连就是让后端重新拉起那一个 MCP。
- **安全**：密钥、令牌、完整路径都不要返回给前端；日志里也要先过滤掉。
- 主题色只存在本地（每台设备可以不一样）；气泡样式和背景存后端。
