# 01 · 首页

路由 `#/`。底栏「首页」。

预览图：`previews/01-home.jpg`（第一屏）、`01-home-full.jpg`（整页）、`01-home-note.jpg`（他此刻 + 留言板）、`01-home-together.jpg`（一起 + 他的动态）、`01-home-contents.jpg`（目录）。

代码：`src/pages/Home.jsx`，区块在 `src/components/home/`，数据层 `src/lib/home.js`。

## 页面上有什么

从上到下四层纸带，越往下颜色越深。每一块都能点进对应的页面。

| 区块 | 内容 | 点了去哪 |
|---|---|---|
| 顶部 | 两个人的名字、问候语（按时间自动换：早上好 / 中午好 / 下午好 / 晚上好 / 夜深了）、在一起多少天、开始的日期、一张蓝晒图 | 右上角铃铛：滑到「他的动态」 |
| 天气 | 城市、天气、温度、湿度、体感、最高最低，下面一句他说的话（手写体） | — |
| 他此刻 | 十六维情绪画成一株叶子标本（越强叶子越长越深）、心情、体温、呼吸（波浪疏密跟着变）、和弦（画在五线谱上）、最强的三维 | 心潮 |
| 留言板 | 最新一条留言（便签 + 火漆 + 回形针）、谁留的、日期、一共多少条；下面一条搜索框 | 留言板；搜索框去留言板搜索，「按日期」去留言板日历 |
| 一起 | 一起听：正在放的歌、进度，可以直接暂停 / 播放；一起看：下一部要看的片子，做成电影票 | 一起（听 / 看） |
| 他的动态 | 独处、记忆、照片墙的最近几条，没看的有数字；「全部已读」 | 独处去小屋、记忆去心潮、照片去小屋照片墙 |
| 目录 | 聊天、小屋、心潮、一起、留言板、续火花、设置七个入口 | 对应页面 |

蓝晒图：后端给一张照片地址，前端会自动处理成蓝晒效果；不给就画植物。

## 后端要准备什么（建议）

一个接口给全页：`GET /api/home`。失联时返回 `available: false`，页面会显示「暂时连不上他那边」。字段的准确名字以 `src/lib/mock.js` 为准。

| 部分 | 要给的东西 | 从哪来（建议） |
|---|---|---|
| 现在 | 服务器当前时间（按她的时区） | 问候语和「几小时前」都按这个算，避免手机时间不准 |
| 名字 | 她和他的名字 | 设置里填的 |
| 在一起 | 开始日期；天数可以给也可以不给（不给前端自己算） | 设置里填的 |
| 问候 | 问候语后半句（例如「今天也辛苦了」） | 可以每天让他写一句，没有就不显示 |
| 蓝晒图 | 一张照片地址，可空 | 设置 · 美化里选的 |
| 天气 | 城市、天气文字、图标（cloud / sun / rain / snow / fog）、温度、体感、最低最高、湿度、他的一句话 | 天气接口按她的位置查；那句话建议每天早上让他看完天气写一句，缓存一天 |
| 他此刻 | 心情一句话、体温、呼吸（文字 + 0–1 的快慢）、和弦名、十六维情绪（每维：名字、0–1 的值） | 心潮的实时状态。维数、名字、顺序都以后端为准，前端给几维画几片叶子 |
| 留言 | 最新一条：谁留的、内容、时间；总条数 | 留言板 |
| 一起听 | 歌名、歌手、当前进度、总时长、是否在放 | 一起听的播放状态 |
| 一起看 | 片名、片单第几部、约好的时间、他的一句话、票号 | 一起看的片单 |
| 他的动态 | 最近 3 条：类型（solo 独处 / memory 记忆 / photo 照片）、标题、一句话、时间、没看的数量 | 他自己活动时写下的记录、新写入的记忆、照片墙 |

另外两个小接口：

| 做什么 | 接口 | 说明 |
|---|---|---|
| 全部已读 | `POST /api/activity/read` | 把他的动态都标成已读 |
| 暂停 / 播放 | `POST /api/together/listen` | 传「是否在放」；和一起听页共用 |

建议：

- 首页一打开就要请求，**整个接口尽量 300ms 内返回**。天气和他的那句话缓存起来，不要每次现查。
- 他此刻的数据也可以缓存几分钟，首页不需要秒级刷新。
- 天气里不要返回她的精确位置，城市名就够。

## 验收

- [ ] 页面和效果图一致（默认蓝晒色）
- [ ] 问候语按时间变，天数对
- [ ] 每块都能点进对应页面；目录七个入口都对
- [ ] 一起听能直接暂停 / 播放，唱片跟着转 / 停
- [ ] 「全部已读」后数字和铃铛上的点都消失
- [ ] 接口失联时显示提示，不白屏
