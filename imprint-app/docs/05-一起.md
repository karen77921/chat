# 05 · 一起（听 · 歌单 · 看）

路由 `#/together`，分页 `?tab=listen|watch`，`?playlist=1` 打开歌单。首页「一起」、小屋「一起」入口、目录 IV、悬浮小窗都会进来。

预览图：`previews/05-together.jpg`（一起听）、`05-together-playlist.jpg`（歌单）、`05-together-search.jpg`（搜歌加歌）、`05-together-watch.jpg`（一起看）、`05-mini.jpg`（悬浮小窗收起）、`05-mini-open.jpg`（展开）。

代码：`src/pages/Together.jsx`；一起听的状态在 `src/lib/listen.jsx`（一起页、悬浮小窗、首页卡片共用）；悬浮小窗 `src/components/together/MiniPlayer.jsx`。

## 页面上有什么

| 区块 | 说明 |
|---|---|
| 一起听 | 蓝晒封套 + 黑胶（在放时转）；同步条（两人头像 +「同步中 · 你们听到同一秒」）；歌名、谁选的；进度条（可点可拖，上面的小刻度是他留便签的位置）；上一首 / 播放暂停 / 下一首 |
| 他边听边写 | 他在某一秒留下的便签；点一张跳到那一秒；还没放到的淡一点 |
| 歌单 | 两个人一起攒：搜歌名 / 歌手加进来；每首写着谁加的；点一首就放；拖右边的三道杠换顺序；× 拿掉 |
| 一起看 | 画面（共影同步播放）、进度；他在当前进度附近的反应（便签）；同步条；片名；有共影房间地址时显示「去共影接着看」 |
| 片单 | 看完的（带评分）、正在看的、约好的（带时间）、想看的；「＋ 加一部」可以顺便约个时间 |
| 悬浮小窗 | 在放歌时，其他页面角上浮一枚胶囊（小唱片 + 歌名 + 暂停），可以拖到别处（位置记在本地）；点一下展开成小播放器，能切歌、看他的便签、回到「一起」或关掉。一起页和聊天页里不出现 |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

### 一起听

| 做什么 | 接口 | 说明 |
|---|---|---|
| 现在的状态 | `GET /api/together/listen` | 名字、正在放的歌（id、歌名、歌手、时长、播放地址、谁选的）、在不在放、放到第几秒、两个人是不是在同步、他这首的便签（第几秒、内容）、歌单（每首：id、歌名、歌手、时长、谁加的） |
| 控制 | `POST /api/together/listen` | 传其中一个：在不在放 / 跳到第几秒 / 上一首、下一首 / 放某一首。返回最新状态 |
| 搜歌 | `GET /api/music/search?q=` | 歌名、歌手、时长、id |
| 加进歌单 | `POST /api/together/playlist` | 歌的 id |
| 换顺序 | `PUT /api/together/playlist` | 全部 id 按新顺序 |
| 拿掉 | `DELETE /api/together/playlist/{歌id}` | |

建议：

- **同步**：状态以后端为准，返回「放到第几秒」和「这个状态的时间」；前端每 30 秒拉一次对齐，中间自己走秒。要更实时，可以加一条推送（和聊天一样的 SSE）在暂停、切歌时通知。
- **他也在听**：给他「切歌 / 暂停 / 加歌 / 在这一秒留一句」的工具；他留的便签就是「他边听边写」。不要后台替他自动生成。
- **歌从哪来**：接甲方自己能合法播放的音源（音乐平台的开放接口或自己的曲库）；播放地址建议带有效期。拿不到播放地址时，前端只走进度、不出声。
- 首页的「一起听」卡片、小屋的入口读的也是这一份状态。

### 一起看（共影）

一起看的同步播放用**共影**：两个人在共影的同一个房间里看，进度由共影对齐。搭法：在小红书搜「共影 教程」，照着搭就行。

| 做什么 | 接口 | 说明 |
|---|---|---|
| 一起看 | `GET /api/together/watch` | 现在在看的（片名、片单第几部、进度、时长、在不在放）、他的反应（第几秒、内容）、片单、共影房间地址 |
| 加一部 | `POST /api/together/watch/list` | 片名、约的时间（可空） |
| 改状态 / 打分 | `PATCH /api/together/watch/list/{id}` | 状态（想看 / 约好了 / 正在看 / 看完了）、评分 |

建议：

- 进度和「在不在放」从共影那边读（或者共影房间每隔一会儿回报一次），这个页面只做展示和入口。
- 他看的时候想说话，就写成「反应」（第几秒 + 一句），页面会贴在画面旁边。
- 约好的时间到之前，经推送提醒两个人；续火花里换来的「今晚陪你看一部」也落到这个片单。

## 验收

- [ ] 一起听、歌单、一起看和效果图一致（默认蓝晒色）
- [ ] 播放 / 暂停 / 切歌 / 拖进度都能用，唱片跟着转停；首页卡片、悬浮小窗同步变
- [ ] 他的便签点了能跳到那一秒
- [ ] 歌单能搜、能加、能拿掉、能拖动换顺序，点一首就放
- [ ] 片单显示四种状态；加一部后出现在最后
- [ ] 悬浮小窗：在放时其他页面出现，能拖、能展开、能关；一起页和聊天页里不出现
