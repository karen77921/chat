# 06 · 心潮（此刻 · 记忆 · 梦与觉察）

路由 `#/tide`，分页 `?tab=now|memory|dream`，`?press=1` 打开「压一枚」。底栏「心潮」、首页「他此刻」、目录 III、首页「他的动态」里的记忆都会进来。

预览图：`previews/06-tide.jpg`（此刻）、`06-tide-drives.jpg`（全部驱力）、`06-tide-memory.jpg`（记忆）、`06-tide-press.jpg`（压一枚）、`06-tide-dream.jpg`（梦与觉察）。

代码：`src/pages/Tide.jsx` + `src/components/tide/tide.css`。

## 页面上有什么

| 区块 | 说明 |
|---|---|
| 顶部 | 「心潮」+ 他醒着还是睡着、今天睡了几小时 |
| 此刻 · 十六维情绪 | 一株叶子标本：一维一片叶子，越强越长越深，强的几片旁边写名字 |
| 此刻 · 记录卡 | 心情、体温、呼吸、和弦；最长的三片叶子 |
| 此刻 · 驱力潮汐 | 最强三股驱力今天 24 小时的涨落；「全部 12 股」展开每一股的条和数值 |
| 记忆 | 搜记忆；「压一枚」手动加；热力格子（最近约 17 周，颜色越深那天记得越多）；长期、这周写入、你手动压的三个数；长期记忆做成标本卡（编号、采集日期、标签，你压的会标出来）；最近写入 |
| 压一枚 | 写一句（200 字内）、贴标签（喜好 / 要记住 / 我们 / 小习惯 / 雷区）、「让他也知道」 |
| 梦与觉察 | 昨晚的梦（标题、内容、余韵标签，印在虚化的蓝晒纸上）；觉察：他写在页边的反思（手写体）；更早的梦 |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

| 做什么 | 接口 | 说明 |
|---|---|---|
| 此刻 | `GET /api/tide` | 醒没醒、今天睡了几小时；十六维情绪（key、名字、0–1）；心情、体温、呼吸、和弦；驱力（key、名字、现在的值、今天 24 小时每小时一个值） |
| 记忆 | `GET /api/tide/memory?q=` | 三个数；热力（每天的日期和条数，最近 119 天）；长期记忆（编号、时间、内容、标签、谁记的）；最近写入几条 |
| 压一枚 | `POST /api/tide/memory` | 内容、标签、要不要告诉他；返回新的那条 |
| 梦与觉察 | `GET /api/tide/dreams` | 昨晚的梦（标题、内容、标签、时间）；更早的梦（标题、时间、总数）；觉察（日期、一句话） |

建议：

- **数据从心潮来**：十六维情绪、驱力、作息、梦都是心潮的状态，后端转一层整理成上面的字段就行，不要另算一套。驱力的名字和数量以心潮为准（现在是 12 股），前端给几股画几股。
- **驱力的 24 小时**：心潮每次结算时记一笔，后端按小时取平均；还没到的小时不用给。
- **记忆**：长期记忆来自记忆库；「这周写入」是这周新写的条数。她手动压的一条，标成「她记的」，进记忆库时不要被自动整理合并掉。打开「让他也知道」时，经连接桥告诉他一句「她帮你记了一件事：……」。
- **觉察**：是他自己反思时写下的话（比如每晚整理记忆时写一句），后台不要替他编。
- 这一页数据不需要秒级更新，进页面拉一次就行；首页「他此刻」用的是同一份情绪数据。
