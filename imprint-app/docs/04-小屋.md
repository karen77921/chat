# 04 · 小屋

路由 `#/room`，分页 `?tab=photos|solo|stickers`。底栏「小屋」、首页目录 II、首页「他的动态」里的独处 / 照片都会进来；聊天表情面板的「管理」进表情包。

预览图：`previews/04-room.jpg`（照片墙）、`04-room-solo.jpg`（独处）、`04-room-stickers.jpg`（表情包）、`04-room-photo.jpg`（看一张照片）、`04-room-draw.jpg`（让他画一张）。

代码：`src/pages/Room.jsx`，各块在 `src/components/room/Parts.jsx`。

## 页面上有什么

| 区块 | 说明 |
|---|---|
| 顶部 | 「小屋」，右上角「＋」贴照片（一次最多 9 张） |
| 此刻 | 一扇蓝晒小窗 + 他现在在做什么、一句话、几点开始、已经多久 |
| 一起 | 一起听（正在放的歌）、一起看（下一部、约的时间），点进「一起」页 |
| 照片墙 | 拍立得两列，贴纸胶带、手写说明、标「他贴的 / 我贴的」，收藏的右上角有小心。筛选：全部 / 他贴的 / 我贴的 / 聊天里的 / 收藏 |
| 看一张照片 | 放大的拍立得；下面是两个人写的话（便签）；收藏 / 写一句 / 删掉 |
| 独处 | 按天的时间线：做了什么、记下的话（手写体引用）、「想到的」 |
| 表情包 | 他画的（旁边「让他画一张」：写一句想要什么）；我的（上传，长按删除）。这两组在聊天表情面板里都能直接发 |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

| 做什么 | 接口 | 说明 |
|---|---|---|
| 小屋顶部 | `GET /api/room` | 现在时间、名字、此刻（在做什么、一句话、开始时间）、一起听（歌名、在不在放）、一起看（片名、时间）、照片总数、这个月独处次数 |
| 照片墙 | `GET /api/room/photos` | 参数 `who`（him / me）、`source`（chat）、`fav=1`。每张：地址、缩略图、说明、谁贴的、来源、收藏没、时间、下面写的话（谁、内容） |
| 贴照片 | 先 `POST /api/chat/upload`（kind 写 photo），再 `POST /api/room/photos` | 地址、说明 |
| 收藏 / 取消 | `POST /api/room/photos/{id}/fav` | 切换 |
| 写一句 | `POST /api/room/photos/{id}/notes` | 100 字以内 |
| 删掉 | `DELETE /api/room/photos/{id}` | |
| 独处 | `GET /api/room/solo` | 每条：时间、做了什么、一段记录、记下的话（可选）、想到的（可选）；这个月几次；分页游标 |
| 表情包 | `GET /api/stickers` | 「我的」和「他画的」；他画的可带当时的描述 |
| 上传表情 | 先 `POST /api/chat/upload`（kind 写 sticker），再 `POST /api/stickers` | |
| 删表情 | `DELETE /api/stickers/{id}` | 只能删「我的」 |
| 让他画一张 | `POST /api/stickers/draw` | 她写的描述；返回「收到」就行，画好后加进「他画的」 |

建议：

- **此刻**：取他最新一条还没结束的独处记录；他不在独处时可以显示「在等你」之类的一句，或者整块不给（前端就不显示）。
- **独处**：他自己活动（自由时间、读书、听歌、整理记忆）时，让他写一条：做了什么 + 一段话；「想到的」是他自己愿意说的感想，没有就不写。不要后台替他编。
- **照片自动进来**：聊天里发的图存的时候顺手在照片表记一条（来源 chat），不用复制文件；聊天里删了，这里也删。
- **他也能贴**：给他「贴一张照片」「给照片写一句」的工具，`from` 记 him。
- **让他画一张**：经连接桥告诉他「她想要一个表情：……」，由他决定怎么画；或者后端调图片生成，把他的画风参考图一起传，保持一个画风。画好裁成正方形、去背景、压到 300×300 左右，再经推送告诉她。用到再画，不要一次批量生成。
- 照片地址建议带有效期的签名；列表给缩略图（宽 300 左右），点开再给原图。
