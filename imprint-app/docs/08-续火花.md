## 页面上有什么

底部三个分页：火花 / 礼物铺 / 收藏。

| 分页 | 内容 |
|---|---|
| 火花 | 连续多少天（一张蓝晒小图：蜡烛和白色的火，火苗会轻轻晃）；今天两个人各自说过话没有；最近七天（邮戳打勾，今天实心）；续火卡几张（每满 7 天一张，断了的那天点「补上」）；两只钱包（各自的积分）；里程碑（7 / 30 / 100 天的奖励） |
| 礼物铺 | 顶上看谁的钱包（默认看他的，只看不扣），可以切成看自己的；分类：全部 / 气泡 / 挂件 / 约会 / 真礼物 / 盲盒；礼物卡：小画、名字、一句说明、多少分、换过的标「已收好」 |
| 换一个 | 说明 + 用谁的积分：自己的（不够就点不了）或「让他换给我」（问过他，他同意了才扣） |
| 收藏 | 气泡与挂件：换到的皮肤，开关「使用中」（同一类只能用一个）；兑换记录：谁换的、什么时候、现在的状态（等他点头 / 约好了 / 已收好 / 已兑现） |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

| 做什么 | 接口 | 说明 |
|---|---|---|
| 火花 | `GET /api/spark` | 现在时间、名字、连续天数、今天两个人说过话没有、最近七天（日期、续上没）、续火卡（几张、每几天一张）、两只钱包的积分、里程碑（天数、奖励、到了没） |
| 用续火卡 | `POST /api/spark/cards/use` | 要补的那天；补上后那天算续上，卡减一 |
| 礼物铺 | `GET /api/spark/shop?cat=` | 名字、两只钱包、礼物列表（id、分类、小画类型、名字、说明、价格、换过没） |
| 换一个 | `POST /api/spark/redeem` | 礼物 id + 用谁的钱包（me / him）。用她的：够就扣、直接换好；用他的：记一条「等他点头」，交给他决定 |
| 收藏 | `GET /api/spark/kept` | 换到的气泡 / 挂件（名字、分类、什么时候换的、在不在用）；兑换记录（名字、谁换的、时间、状态、一句说明） |
| 用上 / 不用 | `POST /api/spark/kept/{id}/active` | 同一类打开一个，其他自动关掉 |

建议：

- **怎么算续上**：按她的时区，一天之内她发过至少一条、他也回过至少一条，这一天就算续上。零点结算一次。
- **积分怎么来**：比如每天续上各加 1 分，里程碑另加；她的和他的分开记。具体数字甲方定。
- **他的钱包**：他能用自己的积分主动给她换礼物（给他一个「送她一个礼物」的工具）；她点「让他换给我」时，经连接桥告诉他「她想要：……，要用你的 60 分」，由他决定同意还是不同意，结果写进兑换记录。
- **约会类礼物**（看一部、睡前故事）：换好后变成一条「约定」，在「一起」页或聊天里提醒；兑现了把状态改成「已兑现」并写一句说明。
- **真礼物**：需要线下寄送的，后端记下来，由甲方人工处理。
- **气泡 / 挂件**：打开「使用中」后，聊天页的气泡样式、头像挂件跟着变（换皮肤用的样式名由后端给，前端按名字套用）。

## 验收

- [ ] 三个分页和效果图一致（默认蓝晒色）
- [ ] 天数、今天两人状态、七天打勾都对；断了的那天能用续火卡补上
- [ ] 礼物铺分类能切；钱包能切换着看
- [ ] 用自己的积分换：够了扣分、出现在收藏和记录里；不够点不了
- [ ] 让他换：记录里出现「等他点头」
- [ ] 收藏里同一类只能有一个「使用中」
