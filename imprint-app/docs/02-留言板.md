# 02 · 留言板

路由 `#/notes`。首页「留言板」区块、今日留言、搜索框、目录 V 都会进来。

网址参数：`?q=关键词`（直接搜）、`?search=1`（进搜索）、`?date=1`（打开日历）、`?day=2026-10-09`（只看这天）、`?new=1`（写一条）。

预览图：`previews/02-notes.jpg`（列表）、`02-notes-search.jpg`（搜索）、`02-notes-calendar.jpg`（按日期）、`02-notes-write.jpg`（写一条）、`02-notes-posted.jpg`（贴上去以后，盖了火漆的排最前）。

代码：`src/pages/Notes.jsx`，组件在 `src/components/notes/`（`NoteCard` 一条留言、`CalendarSheet` 日历、`WriteSheet` 写一条），数据层 `src/lib/notes.js`；底部弹出的纸是 `src/design/Sheet.jsx`。

## 页面上有什么

| 区块 | 说明 |
|---|---|
| 搜索框 | 点一下进搜索；停顿一下或按回车开始找，结果里的关键词用马克笔划出来；右边「×」退出 |
| 日历键 | 打开日历：有留言的日子下面有点（实心 = 他留的，空心 = 我留的），点一天看那天有几条，「看这天的留言」只列这一天；列表上方出现「10月9日 ×」，点掉恢复 |
| 筛选 | 全部 / 他留的 / 我留的 / 盖了火漆；搜索时换成 全部时间 / 这个月 / 今年 / 选日期 |
| 列表 | 按月分组；盖了火漆的排最前（置顶），其余从新到旧。每条有三种纸：横线纸、撕边纸（贴纸胶带）、蓝晒卡；下面是手写署名和时间 |
| 写一条 | 右上角「＋」或底部浮着的按钮。选纸 → 写（最多 300 字）→ 要不要盖火漆（置顶）→ 贴上去。贴上去的那条会「落」到列表最上面，盖了火漆的会有盖章动效 |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

| 做什么 | 接口 | 说明 |
|---|---|---|
| 列表 / 筛选 / 搜索 | `GET /api/notes` | 参数：`q` 关键词、`who`（him / me）、`pinned=1`、`range`（all / month / year / day）、`date`（range=day 时那一天）。返回：现在时间、两个人的名字、总条数、留言列表（每条：id、谁留的、内容、纸、是否盖火漆、时间）、下一页游标 |
| 日历 | `GET /api/notes/calendar?month=2026-10` | 这个月每天他留了几条、她留了几条（没有留言的日子不用给） |
| 写一条 | `POST /api/notes` | 内容、纸（lined / torn / cyan）、是否盖火漆；返回新的那条 |

建议：

- **排序**：不搜的时候，盖了火漆的排最前，其余从新到旧；搜索和按天看的时候只按时间。
- **分页**：一次 20 条，返回 `nextCursor`，往下滑再要（现在的假数据一次全给了）。
- **搜索**：简单的包含匹配就够；留言多了以后可以加全文索引。按她的时区算「这个月」「今年」「这一天」。
- **他也能留**：给他「留一条」和「看留言」两个工具，他留的 `from` 记成 him。他可以自己选纸，也可以由后端随机。
- **提醒**：她贴上去后经连接桥告诉他「【留言板】她留了一条：……」；他留了以后推送给她。
- **火漆**：同时盖火漆的可以有多条，建议最多 3 条，再盖就把最早的那条取消掉。
- 内容去掉前后空格，最多 300 字；后端也要卡长度。

- [ ] 四个筛选都对；盖了火漆的排最前

- [ ] 日历上有留言的日子有点，分得清他和她；选一天后只列这一天，点「×」恢复
