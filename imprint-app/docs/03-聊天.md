## 页面上有什么

| 区块 | 说明 |
|---|---|
| 背景 | 一张虚化的蓝晒图，上面一层白纱；后端给了聊天背景图就用那张（设置 · 美化里换） |
| 顶部 | 返回、他的头像和名字、一行状态（在线 / 回复中… / 仍在等待… / 好像卡住了）、搜聊天、右上角去「美化」 |
| 消息 | **只有文字句子用气泡**（他的偏白，她的偏浅蓝）。其他：多张图片（最多 9 张，点开看大图、左右翻）、语音条（播放、转文字）、文件卡、表情、命令行（可以收起）、引用（气泡里带原话）、「想了一下」（可以展开） |
| 失败占位 | 他那条没写完就断了：虚线气泡，留着写了一半的字，可以「重新生成」或「编辑」（改她上一条再让他重写） |
| 状态 | 最后一条下面**一行小字**：回复中 → 超过 30 秒没新动静「仍在等待 · 已经 N 秒」（可暂停）→ 超过 2 分钟「好像卡住了」（重试 / 再等等） |
| 输入 | ＋（相册 / 拍照 / 文件 / 表情）、输入框（按住麦克风说话，松开发送、滑走取消）、表情。**回车只把消息发出去**，Shift + 回车换行；攒几条后按「回复 N」他才开始回；他在回的时候这个键变成「暂停」 |
| 长按 | 引用、复制、重新生成这条（他的）、编辑（她的文字）、删除；他的消息下面还有一排表情可以直接回应 |
| 时间 | 同一个人连续几条只在最后一条下面写时间；她最后一条后面写「他还没开始回」/「已读」；跨天有日期条 |

## 后端要准备什么（建议）

失联时统一返回 `available: false`。字段的准确名字以 `src/lib/mock.js` 为准。

### 接口

| 做什么 | 接口 | 说明 |
|---|---|---|
| 打开聊天 | `GET /api/chats/{id}` | 对话名字、是窗口还是群、成员（id、名字、头像）、她的名字、聊天背景、在不在线、最近的消息（一次 50 条，`before` 往前翻）、他现在在不在回（null 或 开始时间 + 最后一次动静的时间） |
| 实时推送 | `GET /api/chats/{id}/stream`（SSE） | 两种事件：「消息」（新的或更新的，按 id 覆盖）、「状态」（在不在回；她的消息被看过时带一个「已读」） |
| 发一条 | `POST /api/chats/{id}/messages` | 类型和内容（文字 / 多张图片 / 语音 / 文件 / 表情），可带引用。**只存，不让他开始回**，状态是「待回复」 |
| 让他回 | `POST /api/chats/{id}/reply` | 把所有「待回复」的消息一起交给他；群聊可带「让谁回」 |
| 暂停 | `POST /api/chats/{id}/pause` | 停掉正在进行的回复；已经写出来的部分保留 |
| 重新生成 | `POST /api/chats/{id}/messages/{消息id}/regenerate` | 删掉他这条，重新回 |
| 编辑 | `PUT /api/chats/{id}/messages/{消息id}` | 只能改她自己的文字 |
| 删除 | `DELETE /api/chats/{id}/messages/{消息id}` | |
| 表情回应 | `POST /api/chats/{id}/messages/{消息id}/react` | 表情 id |
| 上传 | `POST /api/chat/upload` | 表单上传，`kind` 写 image / voice / file；返回地址（图片最好再给一个缩略图地址） |
| 表情包 | `GET /api/stickers` | 「我的」和「他画的」两组；内置的 8 个前端自带 |

### 消息的样子（每条都有：id、谁发的、类型、时间、状态）

| 类型 | 要的东西 |
|---|---|
| 文字 | 文字；可带引用（被引用那条的 id、谁的、文字） |
| 图片 | 图片列表（地址、缩略图、宽高），一条最多 9 张 |
| 语音 | 地址、秒数；他的语音建议带「转文字」 |
| 文件 | 文件名、大小、地址 |
| 表情 | 内置的给 id，其他的给图片地址 |
| 命令行 | 一句标题（例如「查了一下天气」）、命令、输出、退出码、用时 |
| 额外 | 「想了一下」的内容（他回之前的思考，可选）；表情回应；改过没有 |

状态：待回复 / 已发出 / 失败（他那条断了，带写了一半的字）。

### 建议

- **「回复中」怎么判断**：后端在他开始回时推一次状态，之后每写出一段、每跑一条命令都更新「最后一次动静」。前端按这个时间自己算「仍在等待」（30 秒）和「卡住了」（2 分钟），所以**中间要持续推动静**，不然会误报卡住。
- **边写边推**：他的消息可以先推一个空的，再不断用同一个 id 推更新的文字，前端会原地覆盖。
- **断了**：模型出错或超时时，把这条标成「失败」并保留已写的部分，推一次状态 null。
- **命令行**：他调用工具时，把命令和输出存成一条「命令行」消息；输出很长的话截到 2000 字以内。
- **语音**：她发的语音建议后端转成文字再交给他；他的语音由后端合成后给地址和秒数。
- **图片和文件**：地址建议带有效期的签名，不要公开可访问；图片一并进「小屋 · 照片墙」。
- **SSE 鉴权**：浏览器的 EventSource 不能带请求头，令牌从网址 `?token=` 取（`src/lib/api.js` 已经这样拼了）。
- 历史分页：往上滑到顶时用 `before`（最早那条的 id）再要 50 条。

## 验收

- [ ] 页面和效果图一致（默认蓝晒色），不显示底栏
- [ ] 回车发出去后不会自动回；「回复」键上的数字对；按了以后状态变「回复中」，他回完消失
- [ ] 30 秒没动静显示「仍在等待」，2 分钟显示「好像卡住了」；暂停、重试都能用
- [ ] 失败占位能重新生成；编辑会把她上一条放进输入框，改完发出去后他重写
- [ ] 一次选多张图能发（最多 9 张）；点开能看大图、左右翻
- [ ] 语音：按住录、松开发；他的语音能播放、能转文字
- [ ] 文件、表情（常用 / 我的 / 他画的）、命令行都显示对
- [ ] 长按菜单五个操作都对；表情回应出现在气泡角上
- [ ] 搜聊天能找到、关键词有划线
